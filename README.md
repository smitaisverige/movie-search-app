🎬 Movie Search App

A modern movie search application built with React, TypeScript, Vite, and Tailwind CSS.
Users can search for movies and instantly view results using the OMDb API.

✨ Features

🔍 Search movies by title

🎞 Display movie posters, titles, and release years

⚡ Fast performance with Vite

🎨 Responsive UI with Tailwind CSS

🧩 Component-based architecture

🔐 Environment variable support for API keys

📱 Mobile-friendly layout


🛠 Tech Stack

React

TypeScript

Vite

Tailwind CSS

OMDb API

📸 Components Overview

SearchBar : Handles movie search input and triggers API requests.

MovieList : Displays all fetched movies in a responsive grid.

MovieCard : Shows movie poster, title, and release year.

Footer :  Simple footer with dynamic copyright year.

🌐 API Used

This project uses the OMDb API

🎨 Styling

Tailwind CSS is used for:

Responsive layouts

Hover effects

Grid system

Buttons and forms
